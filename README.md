# 📰 AI 뉴스 기사 카테고리 분류기 (AI News Category Classifier)

이 프로젝트는 인공지능이 복잡한 뉴스 기사를 읽고, 그 핵심 내용을 파악하여 **정치, 경제, 사회, IT/과학** 등의 카테고리로 자동 분류해 주는 똑똑한 웹 애플리케이션입니다. 5070 세대가 AI를 '두 번째 뇌'로 활용하여 정보를 효율적으로 관리할 수 있도록 돕는 실전 디지털 도구입니다.

---

## 1. 프로젝트 소개
본 애플리케이션은 인공지능의 **문서 분류(Text Classification)** 기술을 기반으로 제작되었습니다. 수많은 정보가 쏟아지는 디지털 시대에, 내가 읽고 있는 글이 어떤 분야의 내용인지 인공지능이 대신 판단해 줌으로써 정보 습득의 속도를 높여줍니다.

* **제작 목적:** 인공지능의 학습 원리를 이해하고, 나만의 결과물을 웹 서비스 형태로 직접 배포하여 성취감을 느끼기 위함입니다.
* **핵심 원리:** 단어의 출현 빈도와 중요도를 수치화하는 **TF-IDF** 기법과 확률 기반의 **나이브 베이즈(Naive Bayes)** 알고리즘을 사용했습니다.

---

## 2. 주요 기능 (Key Features)
1.  **실시간 자동 분류:** 뉴스 본문을 복사해서 붙여넣기만 하면 AI가 즉시 카테고리를 판별합니다.
2.  **분류 신뢰도(Score) 제공:** 인공지능이 해당 카테고리로 판단한 근거를 백분율(%)로 보여주어 판단의 정확성을 시각화합니다.
3.  **데이터 시각화 차트:** 다른 카테고리일 가능성까지 막대그래프로 한눈에 비교할 수 있게 제공합니다.
4.  **반응형 웹 디자인:** 컴퓨터는 물론 스마트폰에서도 자유롭게 접속하여 사용할 수 있는 세련된 화면 구성을 갖추고 있습니다.

---

## 3. 기술 스택 (Technology Stack)
시니어들도 쉽게 따라 할 수 있는 파이썬(Python) 기반의 최신 도구들을 사용했습니다.
* **언어:** `Python 3.10+`
* **웹 화면 제작:** `Streamlit` (복잡한 코딩 없이 웹 페이지를 만드는 도구)
* **인공지능 학습:** `Scikit-learn` (머신러닝 표준 라이브러리)
* **데이터 관리:** `Pandas`, `NumPy`
